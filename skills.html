Skills I Learned

This page explains some of the most useful web development concepts I practiced in COSW 10 and how they appear in my projects.

Sk

Three Important Concepts

1. Semantic HTML

I learned how to use meaningful tags such as header, nav, main, section, article, aside, and footer. These tags help organize a page and make the structure easier to understand.

2. External CSS

I practiced separating design from content by keeping my styling in an external CSS file. This makes the website easier to update and keeps the HTML cleaner.

3. Responsive Layout

I learned how to build layouts that adjust for different screen sizes. This portfolio uses CSS grid and media queries so the cards stack more clearly on smaller screens.

De

Design Skills Demonstrated

I used a consistent color palette, Google fonts, image styling, navigation states, clear headings, and custom project sections to make the site feel like one complete portfolio instead of separate class pages.

  • Using one external stylesheet for layout, typography, color, and spacing.
  • Creating a navigation menu that connects all pages of the website.
  • Adding images with clear alt text for accessibility.
  • Using custom sections and project links to make descriptions easy to scan.
  • Keeping one h1 heading per HTML page.
